# General

This guide helps healthcare organizations connect software that exchanges health information (for example, using FHIR). It describes ways to make those connections more secure and easier to manage, building on OAuth 2.0, a widely used method for controlling an app’s access to information.

The guide covers software used by individuals as well as software that connects organizations. It explains how an app can learn what security methods a server supports, register with a server, and prove its identity using digital certificates and cryptographic keys. It also describes how people and organizations can be authenticated and how requested access can be communicated.

Organizations that adopt the guide as a community still need to agree on their own policies—for example, who may participate, how certificates are issued and checked, and what kinds of data access are allowed. The guide provides a technical framework; it does not set those community agreements.
